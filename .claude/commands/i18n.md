# Add i18n Translations

Add new translation keys to both English and Vietnamese locales.

## Arguments
- `$ARGUMENTS`: Namespace and keys (e.g., "series title='Series Title' description='Series description'")

## Instructions

1. **Parse arguments**: Extract namespace and key-value pairs from `$ARGUMENTS`

2. **Add to English locale** at `src/i18n/locales/en/{namespace}.json`:
   ```json
   {
     "existingKey": "existing value",
     "newKey": "New English text"
   }
   ```

3. **Add to Vietnamese locale** at `src/i18n/locales/vi/{namespace}.json`:
   ```json
   {
     "existingKey": "giá trị hiện có",
     "newKey": "Văn bản tiếng Việt mới"
   }
   ```

4. **If new namespace**, create both files and update:
   - `src/i18n/locales/en/index.ts`
   - `src/i18n/locales/vi/index.ts`

## Usage Pattern
```typescript
const { t } = useI18n();

// Simple key
t("title", "series")

// With variables
t("greeting", "common", { name: "John" })

// Pluralization
t("items", "common", { count: 5 })
```

## Available Namespaces
Check existing namespaces in `src/i18n/locales/en/`

## Rules
- Keep keys in camelCase
- Use dot notation for nested keys sparingly
- Always add to BOTH en and vi files
- Use descriptive key names
- For Vietnamese: provide accurate translations or mark as TODO
